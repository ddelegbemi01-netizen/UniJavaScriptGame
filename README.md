# UniJavaScriptGame

## About

This is a browser-based Christmas-themed noughts and crosses game built with HTML, CSS and JavaScript.

## Running the game

Open `index.html` in a modern web browser. No server or package installation is required.

## Features

- Two-player mode.
- Easy, medium and hard computer opponents.
- Lifetime wins and draws saved in the browser.
- Best-of-two tournament mode.
- The previous tournament champion receives one two-move undo ability in the next tournament.
- Rules popup and responsive layout for smaller screens.

Tournament progress and the previous champion are also saved in the browser using `localStorage`.

## Project files

- `index.html` contains the game layout and controls.
- `css/style.css` contains the visual styling and responsive rules.
- `js/script.js` contains the game, computer opponent and tournament logic.
