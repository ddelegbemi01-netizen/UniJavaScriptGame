🎄 How to Play 🎄

1. Basic Rules

  • The game is played on a 3 × 3 grid.
  • Player X takes the first turn.
  • Players take turns placing X or O.
  • Get three matching symbols in a row, column or diagonal to win.
  • If all nine squares are filled without a winner, the game is a draw.

2. Game Modes

  • Two Players: Play against another person.
  • Play Against Computer: Challenge the computer.
  • Easy: The computer makes random moves.
  • Medium: The computer uses strategic moves.
  • Hard: The computer uses advanced Minimax decision-making.

3. Best of 2 Tournament

  • The first player to win two rounds becomes champion.
  • Tournament scores track progress towards the championship.
  • Select New Tournament to begin a fresh competition.

4. Champion's Two-Move Undo

  • The previous tournament champion receives one special Undo ability in the next tournament.
  • It removes the last two moves from the current game.
  • The ability can only be used once per tournament.

5. Game Controls

  • Restart Game: Restart the current round.
  • Reset Scoreboard: Clear lifetime wins and draws.
  • New Tournament: Start a new tournament.
